# Phase 9 Prerequisites

| Item | Why | How to check |
|---|---|---|
| Docker Desktop running, stack up | The tests use the real services | `docker compose ps` shows the services running |
| GitHub Actions enabled for the repository (the default) | CI runs on the pull request | The pull request page shows "Checks" |
| (9D) A phone or screen recorder for the demo video | The demo video is recorded by the owner; Claude writes the script | |

Cost: 0. GitHub Actions is free for public repositories and has free minutes for private ones.
